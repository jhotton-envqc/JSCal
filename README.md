# JSCal

Calendrier perpétuel en HTML/CSS/JavaScript permettant de visualiser les jours de paye et les congés fériés de la fonction publique du Québec, avec exportation au format ICS compatible Outlook. Il y a aussi un calculateur de jours ouvrable entre deux dates.

## Fonctionnalités

### Calendrier annuel

- Affichage complet des 12 mois d'une année
- Navigation vers l'année précédente ou suivante
- Retour rapide à l'année courante
- Compatible avec les navigateurs modernes

### Jours de paye

- Calcul automatique des jours de paye selon un cycle de 14 jours
- Mise en évidence visuelle dans le calendrier
- Exportation au format ICS

### Congés fériés

Calcul automatique des congés suivants :

- Jour de l'An
- Lendemain du Jour de l'An
- Vendredi saint
- Lundi de Pâques
- Journée nationale des Patriotes
- Fête nationale du Québec
- Fête du Canada
- Fête du Travail
- Action de grâces
- Veille de Noël
- Noël
- Lendemain de Noël
- Veille du Jour de l'An

### Exportation ICS

Deux fichiers peuvent être générés :

#### Congés fériés

Importation dans Outlook avec le statut :

```text
Absent du bureau
```

#### Jours de paye

Importation dans Outlook avec le statut :

```text
Disponible
```
